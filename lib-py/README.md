# Solfege Detector

A Python library that analyzes an audio stream in real-time and detects when a solfege syllable is spoken/ sung.

## Install Dependencies 

The below command will install dependencies listed in `pyproject.toml`

```bash
uv sync
```

## Run the Python Module

```bash
uv run app.py
```

## Run Tests

```bash
uv run pytest
```

## Install CLI Globally

```bash
uv tool install .
```

## End-User Installation and Configuration of Program

You can install this program locally which includes a cli named solfege-detector by

```bash
pip install .
source .env
solfege-detector
```
